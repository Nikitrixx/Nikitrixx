NOVA STREAM — START HERE

IMPORTANT: Do not open index.html while viewing the ZIP archive.

1. In Windows Downloads, right-click nova_stream_fixed.zip and choose “Alle extrahieren…” (Extract All).
2. Open the newly extracted folder named nova_stream_fixed.
3. Double-click index.html to open the website in your browser.
4. Keep styles.css, app.js, manifest.webmanifest, sw.js and the assets folder together with index.html. Do not move index.html by itself.

If the page still appears unstyled, check that styles.css is in the same folder as index.html and assets/hero-concept.png exists inside the assets folder.

This is a demo website, not yet a full streaming service. Only upload films you made yourself or have permission to distribute.

To publish with GitHub Pages, upload the CONTENTS of this folder (index.html, styles.css, app.js, manifest.webmanifest, sw.js, assets folder) to the root of your repository. Ask a parent/guardian to help with public publishing and privacy/legal requirements.
